# Zalo Bulk Out Group 🚀

Tiện ích mở rộng (Chrome Extension) giúp bạn tự động rời hàng loạt nhóm trên Zalo Web (`chat.zalo.me`).

## 🎬 Demo


> 📌 **Ghi chú cập nhật:** Phương án và mã nguồn của công cụ này đã được test và đang hoạt động rất tốt, tương thích hoàn toàn với giao diện và cấu trúc DOM của phiên bản Zalo Web tính đến ngày **26/09/2026**.

## 📦 Cài đặt

1. Tải toàn bộ mã nguồn về máy.
2. Mở trình duyệt Chrome/Edge, truy cập vào: `chrome://extensions/`
3. Bật **Developer mode** (Chế độ dành cho nhà phát triển) ở góc phải.
4. Chọn **Load unpacked** (Tải tiện ích đã giải nén) và chọn thư mục vừa tải về.

## 🚀 Hướng dẫn sử dụng

1. Vào [Zalo Web](https://chat.zalo.me/) và mở tab **Danh sách nhóm và cộng đồng**.
2. Ở bảng điều khiển góc phải màn hình, bấm **1. Bật Checkbox Chọn Nhóm**.
3. Tick chọn các nhóm bạn muốn rời khỏi.
4. Bấm **3. Rời các nhóm đã chọn** và để tool tự động thao tác.

*💡 Lưu ý: Zalo sử dụng tính năng cuộn ảo (chỉ load các nhóm đang hiển thị trên màn hình). Khi tool tạm dừng vì không tìm thấy nhóm, bạn chỉ cần dùng chuột cuộn danh sách xuống dưới, tool sẽ nhìn thấy nhóm mới và tự động chạy tiếp.*
